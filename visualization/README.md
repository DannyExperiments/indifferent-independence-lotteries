# Convex indifference classes

Extract the ZIP and open index.html locally. Choose a lottery or adjust the horizontal share in the mixture. Drag sideways, or focus the plot and use the arrow keys. The plane is the two-dimensional outcome space. Stem height gives an atom's positive probability. The white diamond marks the mean.

The horizontal and vertical lotteries in Lederman's example are both good and have mean zero. Every mixture of them is in the same convex indifference class as the sure zero outcome. The antidiagonal pair also has mean zero, but it cannot be built from good components with that mean and is incomparable with the sure outcome in the constructed preorder.

Use Python 3.11 or newer and Pillow 10.1 or newer. Run python3 visualization/render.py from the repository root to rebuild the looping GIF and the offline ZIP.
