# Scope and limitations

The result is for finite-support lotteries on R^d for finite d with the product order on sure outcomes. The common mixture lottery in Indifferent Independence must belong to the two other lotteries’ indifference class. The theorem uses the positive-mass strict coupling condition in the pinned catalog. Lederman’s generalized lottery definition allows zero weights; those matched atoms are deleted before checking strictness.

Continuity, unrestricted Independence and alternative outcome orders are separate compatibility questions. The replay tests finite generating moves and their transitive closure inside a specified example family. External peer review, formal verification and an exhaustive priority search remain pending.
